Healthy Living Hub - Site Plan

Site Name

Healthy Living Hub

This name represents a friendly resource for people improving their wellbeing through nutrition, exercise and daily habits.

Site Purpose

The purpose of the Healthy Living Hub is to provide simple, reliable information about healthy living, including nutrition guides, exercise routines and mental wellness.

Scenarios

  • What are some easy, healthy meals I can start making today?
  • How can I start a simple workout routine at home?

Color Schema

  • #2E8B57 - Sea Green: headings, nav background, accents
  • #F5F5F5 - Light Gray: background
  • #333333 - Charcoal: body text

Typography

  • Poppins: headings
  • Roboto: body text
